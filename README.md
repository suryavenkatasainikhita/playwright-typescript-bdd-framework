Playwright TypeScript BDD Framework

Automation framework built using Playwright, TypeScript, and Cucumber BDD following Page Object Model (POM) design principles.

🚀 Overview- This framework demonstrates scalable UI automation using Playwright with TypeScript and Cucumber BDD.

🛠 Tech Stack - Playwright (TypeScript) • Selenium WebDriver • Cucumber BDD • TestNG • Java • SQL • Jenkins • Git

📁 Project Structure - pages - Page Object classes, tests - Test scripts, features - Cucumber feature files, utils - Utility functions, config - Project configuration

🔥 Features - Page Object Model (POM), Playwright Automation, Cucumber BDD Support, Reusable Utilities, Scalable Framework Design, CI/CD Integration Support
